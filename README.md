# Swathi Mohan — personal website

Source for [swathi-mohan.vercel.app](https://swathi-mohan.vercel.app), built with Next.js.

- `app/page.tsx` — page content (research, background, links)
- `app/Sketch.tsx` — the small interactive sketch shown under each research item
- `app/globals.css` — all styling

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm run lint
```
